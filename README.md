# Receitas-INF1A-02

Versão visualmente aprimorada do site da atividade prática de Biologia da turma INF1A, baseada no repositório `Receitas-INF1A`.

## O que foi preservado

- Autenticação e contas pelo Supabase.
- Seis grupos (`grupo-1` a `grupo-6`).
- Consulta e edição de receitas conforme as permissões existentes.
- Perfil do aluno.
- Painel do professor.
- Organização de usuários e grupos.
- Exclusão de contas de alunos pelo professor.
- Tema claro/escuro.
- QR Code, favicon, sitemap, robots e página 404.
- Migração SQL existente.

## Melhorias visuais

- Identidade visual inspirada em Biologia: verde, teal, tons naturais e detalhes aquáticos.
- Cards com profundidade, transparência e efeitos de hover.
- Barra de progresso de rolagem no topo.
- Elementos aparecem suavemente conforme entram na tela.
- Pequenos atrasos escalonados entre elementos para criar sensação de movimento.
- Fundo com detalhes orgânicos sutis.
- Suporte a `prefers-reduced-motion` para reduzir animações quando o dispositivo solicitar.
- Layout responsivo para celular e desktop.

## Dados

Os grupos e receitas continuam armazenados no Supabase. Nenhuma receita foi inventada ou adicionada ao código: os dados continuam vindo do banco.
